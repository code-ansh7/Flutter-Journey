# 💡 What I Learned

✅ Every Flutter app starts from `main()`.

✅ `runApp()` is responsible for launching the root widget.

✅ Flutter UI is made entirely of Widgets.

✅ MaterialApp is the root Material Design widget.

✅ Scaffold provides the basic screen layout.

✅ Center aligns its child widget to the center.

✅ Text displays text on the screen.

✅ Widgets are connected using a Parent → Child hierarchy.
