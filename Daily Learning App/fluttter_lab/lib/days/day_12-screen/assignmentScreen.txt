------------------------------------------------------------

Budget Planner


🎯 SCREEN OBJECTIVE
------------------------------------------------------------

Create a professional real-world Budget Planner screen
using Flutter input controls and dynamic UI.

The user should be able to:

• Set a monthly budget
• Select budget type
• Select multiple spending categories
• Enable / disable Auto Save
• View a dynamic Budget Summary
• See total allocated amount
• See remaining budget
• See selected categories
• See Auto Save status

============================================================
                 REAL-WORLD LOGIC
============================================================

BUDGET

User Slider move karta hai
        ↓
budget value change hoti hai
        ↓
setState()
        ↓
UI rebuild
        ↓
Budget Summary update


------------------------------------------------------------

BUDGET TYPE

User Monthly / Weekly select karta hai
        ↓
budgetType change
        ↓
setState()
        ↓
Summary mein selected type update


------------------------------------------------------------

SPENDING CATEGORIES

User multiple categories select kar sakta hai

Food
Transport
Shopping
Entertainment

        ↓

Selected category ka budget
        ↓
totalAllocated mein add
        ↓
remainingBudget calculate

remainingBudget = budget - totalAllocated


------------------------------------------------------------

AUTO SAVE

Switch OFF
        ↓
"Auto Save is OFF"

Switch ON
        ↓
"Auto Save is ON"


============================================================
                CALCULATIONS
============================================================

Example:

Total Budget = ₹25,000

Food = ₹8,000
Transport = ₹3,000
Shopping = ₹5,000
Entertainment = ₹2,000


If Food + Shopping selected:

Allocated:

₹8,000 + ₹5,000

= ₹13,000


Remaining:

₹25,000 - ₹13,000

= ₹12,000


If all categories selected:

₹8,000
+ ₹3,000
+ ₹5,000
+ ₹2,000

= ₹18,000


Remaining:

₹25,000 - ₹18,000

= ₹7,000
