# 💡 What I Learned

✅ MyApp is a custom widget.

✅ StatelessWidget allows MyApp to become a Widget.

✅ Flutter renders UI using the build() method.

✅ build() must return a Widget.

✅ Flutter renders only Widgets.

✅ @override replaces the parent's build() method.

✅ const creates immutable widgets that Flutter can efficiently reuse during rebuilds.
