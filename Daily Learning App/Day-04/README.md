# 💡 Developer Notes

✔ Use **Padding** for spacing inside widgets.

✔ Use **Margin** for spacing outside widgets.

✔ Prefer `Center` over large fixed margins when centering widgets.

✔ Always use `const EdgeInsets` whenever possible.

✔ Clean spacing = Better User Experience (UX).

---

# 💼 Real World Usage

Padding is used in:

- Login Screens
- Cards
- Chat Bubbles
- Product Tiles
- Dashboard Widgets
- Buttons
- Forms

Margin is commonly used between:

- Cards
- Sections
- Images
- Buttons
- List Items

---

# ⚠️ Common Mistakes

❌ Confusing Padding with Margin.

❌ Using large fixed margins to center widgets.

❌ Forgetting `const` for immutable EdgeInsets.

❌ Ignoring spacing while designing UI.
